# Glyphs the cartridge does not have.
#
# The game's font is 8 pixels wide by 9 tall, one bit per pixel, and it holds
# capitals but no lower case and no accents. These are the ones we add.
#
# Each glyph is a name on its own line followed by exactly 9 rows of 8
# characters: '#' is ink, anything else is background. Edit them freely; the
# build reads this file, there is no compiled copy.
#
# The rows line up like this, after navi/font.py raises the game's own Latin
# glyphs by one pixel so that everything shares a baseline:
#
#   row 0-1  accents over capitals
#   row 1-2  accents over lower case, tops of ascenders
#   row 3-7  x-height
#   row 7    baseline
#   row 8    descenders
#
# '?' and '!' are not here: the build makes '¿' and '¡' by turning the
# cartridge's own glyphs upside down, so they match its style exactly.
#
# Ink must stay inside columns 2-6 (tests/test_glyph_margins.py enforces it).
# The battle unit panel and the name keyboard draw a 1px outline around each
# glyph inside its own 8px cell, and the NATIVE capitals/digits all run to
# column 6, outline on 7. Only a background pixel in OUR column 0 separates
# the two outlines — start ink at column 2 so that pixel exists. Native
# glyphs are left alone: merged outlines between native pairs are the game's
# own look (katakana, all-caps English, model codes).
