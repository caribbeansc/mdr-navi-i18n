# Proper names: the canonical spelling

Always use the canonical form. The listed variants are wrong and should be
fixed wherever they turn up. The romanisations follow the spellings the game
itself already ships in Latin letters, so the Spanish and English packs name
the same people the same way.

| Canonical | Notes / variants NOT to use |
|---|---|
| **Murasame Shiden** | The idol Medafighter. Not `Siden`, not `Shiden Murasame` (surname first stays Japanese order here). |
| **Rainy** | Shiden's little sister. Not `Reiny`, `Reinī`. She is formal and deferential towards her brother. |
| **Hiyori** | The player's sharp-tongued classmate. |
| **Sachi** | Classmate. |
| **Kirika** | The fortune-teller girl. Speaks in trailing ellipses: `…I see…`. |
| **Tensai** | Of the Kansai trio. |
| **Amamiya** | Of the Kansai trio. |
| **Navico** | The navi-type Medabot. Not `Nabiko`, `Navika`. |
| **Shiratama** | The excitable pirate. Not `Siratama`. |
| **Nyuudou** | Sperobo officer. Not `Nyudo`. |
| **Sekiran** | Sperobo sea officer. |
| **Sperobo Gang** | The gang. Not the anime's `Rubberobo Gang`: this game names its own gang. Members: `the Sperobos`. |
| **Medawatch** | The wrist device (メダロッチ). Dub canon; never `Medarotch`. |
| **«SeeMore»** | Hiyori's mail-order opera glasses (『ミエミエくん』): a pun on seeing more than you should. Quoted «SeeMore» on first mention. |
| **Raiun** | Sperobo sky officer (雷雲). His title is `Sky Boss`; his laugh is `Bwaa ha ha ha!`. |
| **Hiderin** | Classmate rescued in the pit. |
| **Tsunami** | Classmate. |
| **Komechu** | Classmate. |
| **«Power Stone GX»** | The mail-order bait stone; already English, quoted on first mention. |
